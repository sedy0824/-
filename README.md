# Minesweeper (2D Web App)

HTML5 / CSS3 / JavaScript で作成したモダンで軽量・快適な 2D マインスイーパーです。

🎮 **公開 URL (GitHub Pages)**:
👉 https://sedy0824.github.io/-/

---

### ✨ 特徴
- **2D フラット & モダンダークデザイン**: 視認性が高く、どの端末でもサクサク軽量に動作
- **すっきりとした UI 配置**: 画面上部のバーに「残り地雷数」「リセット顔ボタン」「経過時間」「難易度選択」をまとめ、盤面を広々と確保
- **選べる 3 つの難易度**:
  - 🟢 **初級**: 9×9（地雷 10 個）
  - 🟡 **中級**: 16×16（地雷 40 個）
  - 🔴 **上級**: 30×16（地雷 99 個）
- **操作性**:
  - 左クリック: 掘る（オープン）
  - 右クリック: 旗を立てる / 解除
  - ⚡ **数字クリック（コード機能）**: 開封済みの数字マスをクリックすると、周囲の旗の数が一致している場合に残りの未開封マスを一括オープン
- **初手安全機能**: 初回クリックマスとその周囲 8 マスには地雷が配置されず、1 手目での即ゲームオーバーを防止
- **連鎖オープン (Flood Fill)**: 空白（周囲地雷 0）マスを開くと隣接マスを自動でオープン
- **スマホ・タッチ対応**: 「⛏️ 掘る / 🚩 旗」の切り替えトグル & 長押しでの旗立てに対応
- **クリア演出**: クラッカー（紙吹雪パーティクル）でお祝い
- **GitHub Actions 連携**: `main` ブランチに push すると自動で GitHub Pages にデプロイ
