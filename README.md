# 3D Minesweeper (Three.js)

HTML5 / CSS3 / JavaScript と **Three.js** で作成した 3D マインスイーパーの MVP です。

🎮 **公開 URL (GitHub Pages)**:
👉 https://sedy0824.github.io/-/

---

### ✨ 特徴
- **Three.js による 3D ボード**: 立体的なキューブ、3D フラグ、3D 地雷、影・ライティング演出
- **直感的な 3D 操作**: マウスドラッグで自由な視点回転・ズーム、視点リセットボタン
- **初手安全機能**: 初回クリック位置と周囲 8 マスには地雷が配置されず、確実に安全にスタート
- **連鎖オープン (Flood Fill)**: 「0」の周囲の空白マスを自動でオープン
- **難易度切り替え**: 初級 (9×9 / 地雷 10 個)、中級 (16×16 / 地雷 40 個)
- **クリア演出**: クラッカー（紙吹雪パーティクル）でお祝い
- **スマホ・タッチ対応**: 「⛏️ 掘る / 🚩 旗」の切り替えトグル付き
- **GitHub Actions 連携**: `main` ブランチに push すると自動で GitHub Pages にデプロイ
